# 💗 A Little Question — Romantic Date Invitation Website

A cute, interactive, and fully responsive **romantic date invitation** web app built with **HTML, CSS, and JavaScript**. Inspired by the viral "Will you go on a date with me?" trend — this project playfully asks someone special out, with a **shy "No" button** that runs away and a **"Yes" button** that opens a multi-step romantic date planner.

---

## ✨ Features

- 🐻 **Adorable animated bear sticker** at the top of the card
- 💖 **Floating hearts animation** continuously bursting in the background
- 🙈 **Playful "No" button** that evades the cursor (desktop) or tap (mobile)
- 🥹 **"Yes" button** opens a full romantic flow:
  1. Pick a date idea (café, sunset walk, movie, bookshop)
  2. Choose a mood/vibe (romantic, playful, dreamy, heartfelt)
  3. Write a personal note, pick a date, and add a soundtrack
  4. Get a beautiful summary card of "Our Little Date Plan"
- 🎉 **Confetti-like heart bursts** on every interaction
- 📱 **Fully responsive** — works beautifully on mobile, tablet, and desktop
- 🌈 **Smooth animations** with `prefers-reduced-motion` accessibility support
- 🔒 **100% client-side** — no backend, no data collection, no tracking
- 🌐 **Optional Streamlit wrapper** for easy cloud deployment
